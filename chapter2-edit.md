## Style Rules
1. Rule 1: Use direct imperative verbs for instructions; avoid "you have…" declarative sentences.
> Before: You have logged into your GitHub account on a desktop browser (English interface).
> After: Log in to your GitHub account on a desktop browser (English interface).

2. Rule 2: Separate multiple actions in one sentence into individual steps where needed; avoid run-on instructions.

> After:
> 1. Click the plus `+` icon at the top-right of any GitHub page.
> 2. Select **New repository**.

3. Rule 3: Use concise, consistent terminology; remove redundant descriptive words.
> Before: Click the green **Create repository** button.
> After: Click **Create repository**.

4. Rule 4: Turn passive / vague observation into clear check statements for result verification.
> Before: The repository page opens, and you can see the README.md file displayed on the main page.
> After: Confirm that the repository loads and README.md appears on the main page.

5. Rule 5: Remove incomplete sentence fragments; write complete, clear prerequisite statements.
> Before: Stable internet connection.
> After: Ensure you have a stable internet connection.

6. Rule 6: Keep formatting consistent; avoid redundant labels like "Check:" in the verification section.
> Before: ✅ Check: The repository page opens…
> After: ✅ Confirm the repository loads and README.md appears on the main page.
